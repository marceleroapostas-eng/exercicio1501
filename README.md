\# Exercício 1501 - Número por Extenso



\## Descrição



Este programa solicita um número de 0 a 9 ao usuário. Em seguida, verifica o número informado e exibe seu valor correspondente por extenso. Caso o número esteja fora do intervalo permitido, o programa informa que o número é inválido.



\## Tecnologias utilizadas



\- Java



\- NetBeans



\- Maven



\## Entrada



A entrada contém um número inteiro de 0 a 9, informado pelo usuário.



\## Saída



O programa exibe o número informado por extenso. Caso o número não esteja entre 0 e 9, exibe uma mensagem informando que o número é inválido.
